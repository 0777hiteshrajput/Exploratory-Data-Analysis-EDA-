# Exploratory Data Analysis (EDA) Project

## Objective
To analyze the dataset, understand patterns, identify trends, detect outliers, and extract meaningful insights for better decision-making.

## Steps Performed
- Data Importing and Understanding  
- Data Cleaning (handling nulls, duplicates, incorrect values)  
- Exploratory Analysis  
- Feature Understanding and Relationship Study  

## Techniques Used
- Univariate Analysis  
- Bivariate & Multivariate Analysis  
- Outlier Detection  
- Correlation Analysis  

## Visualization
Used visual tools like:
- Histogram / Distplot
- Bar Plot
- Box Plot
- Pairplot
- Heatmap

## Insights
- Identified key patterns and trends
- Found relationships between important features
- Highlighted important business insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Outcome
Clear understanding of dataset structure, hidden patterns, and useful insights to support data-driven decisions.
